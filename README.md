# Customer Churn Prediction and Retention Recommendation System

## 📌 Overview

This project uses machine learning to predict whether a telecom
customer is likely to churn.

The system compares three classification algorithms:

- Logistic Regression
- Random Forest
- XGBoost

The final system provides:

- Churn prediction
- Churn probability
- Risk classification
- Feature importance
- Retention recommendations

## 🎯 Objective

The main objective is to identify customers who are likely to
leave a telecom service so that the company can take preventive
retention actions.

## 📊 Dataset

The project uses the Telco Customer Churn dataset.

The dataset contains customer demographic, service,
contract, and billing information.

## 🧠 Machine Learning Models

### Logistic Regression
Used as the baseline classification model.

### Random Forest
Used to capture nonlinear relationships between features.

### XGBoost
Used as the advanced gradient boosting model.

## 📈 Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## 🔍 Exploratory Data Analysis

The project analyzes relationships between churn and:

- Contract type
- Tenure
- Monthly charges
- Internet service
- Payment method
- Technical support
- Online security
